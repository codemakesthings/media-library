# Django Media Library

[GitHub Repo](https://github.com/codemakesthings/media-library)

A Django project to catalogue a users physical media that includes.

- Movies
  - DVD, Blu-ray, UHD, Video Tape, Laser Disc
- Music
  - CD, Vinyl, Cassetes
- Books
- Games

## Project Overview

Build a Django-based web application that will allow a user to manage and catalog their physical media. This will include the ability to track movies, vinyls, cd’s, and video games.

### Featues

- View media by type
- Add, Edit, Delete Media
- Provide a rating for media
